🛠️ Pense-Bête Déploiement Go (API Porelo)

Toutes les commandes doivent être exécutées dans le répertoire racine du backend : ~/websites/porelo/backend.

1. Correction du Module et Génération du Code (Prisma)

Ces étapes corrigent le problème de résolution du module Go local et génèrent le client DB.

Fichier go.mod

Ajouter la ligne suivante à la fin de go.mod pour résoudre les dépendances locales (chemin du module api) :

replace api => .

Commandes de Génération et de Dépendances

  • Nettoyer et télécharger les dépendances manquantes :
    • go get ./...
  • Correction de la propriété du fichier généré (si l'utilisateur sabrina ne peut pas l'écraser) :
    • sudo chown sabrina:sabrina internal/db/db_gen.go
  • Générer le client Prisma Go (télécharge le binaire requis et écrit db_gen.go) :
    • go run github.com/steebchen/prisma-client-go generate
  • Nettoyer les modules Go après génération :
    • go mod tidy

2. Compilation et Gestion du Service

Ces étapes compilent le code en binaire et gèrent le service systemd.

  • Compiler le code en un binaire nommé app :
    • /usr/local/go/bin/go build -o app .
  • Redémarrer le service systemd :
    • sudo systemctl restart porelo-api.service
  • Vérifier l'état et le journal d'erreur détaillé du service :
    • sudo systemctl status porelo-api.service
    sudo journalctl -xeu porelo-api.service

3. Diagnostic de l'Arborescence (Commandes utilisées)

Commandes clés utilisées pour vérifier l'emplacement des fichiers et des permissions :

  • Vérifier la présence de fichiers Go dans un répertoire :
    • ls -l /home/sabrina/websites/porelo/backend/internal/db
  • Vérifier la propriété et les permissions d'un fichier spécifique :
    • ls -l internal/db/db_gen.go
